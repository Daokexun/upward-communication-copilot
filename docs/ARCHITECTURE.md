# Upward Communication Copilot Architecture

## 核心设计哲学
向上管理不是拍马屁，而是**“管理预期、降低 Leader 决策心智开销、为组织提供高确定性”**。

```mermaid
flowchart TD
    A[日常业务困惑 / 卡点 / 答辩材料] --> B[Step 1: 带选择题对齐协议 (Options-First)]
    B --> C[Step 2: 30秒异步进展同步 (Async Broadcast)]
    C --> D[Step 3: STAR 降维提炼工坊]
    D --> E[Step 4: 职级答辩沙盘对抗质检]
    E --> F[高确定性团队信任 & 顺利晋升/留用]
```
