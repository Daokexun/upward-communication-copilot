# Prompt 01: 带选择题敲门协议 (Options-First Alignment Protocol)

## 核心背景（源自微信支付资深面试官 kaka 亲授）
“职场新人最忌讳的是‘两手空空，带着一个巨大的问答题去找 Leader’——‘Leader 这个怎么办？’
这把思考的成本全部丢回给了 Leader。
真正成熟的向上管理，是把问答题变成选择题。你准备好 A、B、C 三个选项，分析各自利弊、资源开销与 ROI，并附带你推荐的方案和理由。Leader 只需要花 30 秒做决策。”

## 结构化输入与输出
- **背景现状 (Context)**：当前遇到的核心冲突或不确定性
- **方案 A (稳妥基线)**：低风险、按部就班、收益确定
- **方案 B (突破创新)**：有一定试错成本、周期较长，但具备高杠杆
- **方案 C (低成本折中)**：资源受限情况下的最小可行妥协
- **个人倾向与判断依据**：“基于当前 Q3 业务核心 KPI，我推荐推进方案 A，理由是……”
